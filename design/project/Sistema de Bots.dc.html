1Três direções · forma do personagem, paleta e estilo de animação
Bots com personalidade — e cérebro trocável.
Cada bot é um colega persistente: tem nome, rosto, memória e um computador só dele. O cérebro vem de qualquer API de IA e pode ser trocado a qualquer momento — sem perder o que ele aprendeu sobre você.
Persistent AI teammates with a face, a memory and their own computer — powered by whichever model you choose.
O sistema abaixo vale para as três direções. Entre 1a1b1c mudam a forma do personagem, a paleta e o jeito de se mexer.
01Rosto · FaceNome, personalidade, voz e expressões. Cada bot é um personagem com jeito próprio — não uma aba de chat.
02Cérebro · BrainQualquer modelo via API, com sua chave ou com créditos. Dá pra combinar: um cérebro para pensar fundo, outro rápido para o dia a dia.
OpenAIAnthropicxAIGoogleMistralDeepSeekOllama · local+ API compatível
03Memória · MemoryA memória pertence ao bot, não ao modelo. Trocou de cérebro? Ele continua lembrando de você, do seu tom e das suas regras.
04Computador · ComputerCada bot tem um computador na nuvem só dele — navegador, arquivos e terminal — isolado dos outros bots. Você pode espiar a tela a qualquer hora.
05Mãos · AppsConecta Gmail, Slack, WhatsApp, Notion, GitHub e o que mais você usar. Continua trabalhando com seu laptop fechado.
06Limites · GuardrailsPede aprovação antes de ações sensíveis e respeita um orçamento de API por bot. Tudo o que ele faz fica registrado.
